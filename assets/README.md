# README and repository pictures

These pictures are for the README and the GitHub page. The page's own logos, icons, and mascot
live in `public/brand/`.

| File                              | What it is                                                                                          |
| --------------------------------- | --------------------------------------------------------------------------------------------------- |
| `plenipo-horizontal-on-light.png` | The Plenipo logo with Pip, the robot, for light backgrounds. A transparent 3000 × 1194 PNG.          |
| `plenipo-horizontal-on-dark.png`  | The same logo for dark backgrounds.                                                                 |
| `pleni-social-preview.png`        | The Pleni social preview: a 1280 × 640 PNG with a strip of the map from demo mode. Upload this one. |

The two logo files are exact copies of approved Plenipo brand files, made by 8 West Ventures, LLC.
Do not change, crop, recolor, or redraw the logos. Keep each README picture under 400 KB.

`pleni-social-preview.png` is the picture GitHub shows when someone shares a link to the
repository. Its map strip comes from demo mode, never from real sessions. How to upload it, and
the rules for making a new one, are in
[docs/github-repo-settings.md](../docs/github-repo-settings.md#social-preview).
