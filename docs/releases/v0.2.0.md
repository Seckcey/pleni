# v0.2.0 — Send messages and answer questions from Pleni

**Pleni can now act when you ask, not only watch. Send a session a message and answer its
questions, right from your browser.** Each new button is off until you turn it on, and works only
on the computer that runs Pleni. Pleni by **8 West Ventures, LLC**.

## What's new

- **Send messages** (Windows): a **Chat** tab in a session's side panel. Type a message, choose
  Send, and the answer shows there. Pleni never sends to a session that is busy or open somewhere
  else, and it keeps no copy of your message.
- **Answer questions**: Claude Code's questions, plans to approve, and "may I run this?" prompts
  wait in Pleni, under **Needs you**. Pick an answer, approve the plan, or allow the tool. You can
  still answer in the session's own window. Tested with Claude Code 2.1.307.
- **Roll over** a long session to a fresh one, **start a new agent**, **open a session in
  PowerShell**, and **bring a cloud session here** (Windows).
- **Models page**: see and change the model and effort your Codex and Claude Code agents use.
- **Mail page** and agent-mail lines on the map, **Live GitHub status** with **Merge**, a sign-in
  box, pop-up alerts, and more.

## Good to know

- With none of the buttons on, Pleni only reads, as before. It has zero dependencies, and it sends
  nothing anywhere on its own. Only **Live GitHub status**, when you turn it on, asks GitHub
  through your own `gh`.
- A message sent with Pleni runs with no window, so Claude Code asks no questions there. With
  **Also change files in its folder**, its "may I run this?" prompts come to Pleni.
- If you connect **Answer questions** and later close Pleni, Claude Code shows a short "hook error"
  line and asks in its own window as usual. **Disconnect** stops that.

## Try it

You need Node.js 22.12 or newer.

```sh
npx pleni@latest --demo   # look around with a made-up team
npx pleni@latest          # watch your own sessions
```

Every change is in the [CHANGELOG](https://github.com/Seckcey/pleni/blob/main/CHANGELOG.md), and
how to use each button is in the [README](https://github.com/Seckcey/pleni#readme).
