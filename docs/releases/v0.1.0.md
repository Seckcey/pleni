# v0.1.0 — The first version

**Pleni puts your Claude Code, Codex, Grok and Kimi Code sessions on one live map in your browser:
who started whom, what each one is doing, and the work they hand to each other.** The first
version of Pleni, the browser edition of Plenipo by **8 West Ventures, LLC**.

## What's in it

- **Map, List, Activity and Tasks views.** Lines glow as work goes down to a helper and a report
  comes back up.
- **"Needs you"** shows when a session asks a question, wants a plan approved, or waits for
  permission. You can dismiss it.
- **Your chain of command.** Drag a tile onto another, or use the Reports to menu. Ranks can
  follow each session's AI model.
- **Check from your phone** through Tailscale.
- **It only looks.** Pleni never changes a session or its files, nothing leaves your computer, and
  it has zero dependencies.

## Try it

You need Node.js 22.12 or newer.

```sh
npx pleni --demo   # look around with a made-up team
npx pleni          # watch your own sessions
```
